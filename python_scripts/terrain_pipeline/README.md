Terrain and hydrology pipeline for Lumi.

Quick start:
- python python_scripts/run_terrain_pipeline.py

Optional flags:
- --buffer-m 2000
- --polygon-path path/to/municipality_polygons.geojson
- --advanced-hydrology
- --write-geojson
- --write-parquet

Outputs are written to regionalData/output/terrain_metrics by default.
