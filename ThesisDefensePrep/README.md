## Recommended reading / rehearsal order

1. **05 first** — skim §1 (watchlist) + §7 (limitations script) so the caveats are loaded early.
2. **01** — rehearse the script slide-by-slide; time yourself against the ~11–13 min budget.
3. **03** — learn the decision log (D1–D25); that's where "why did you…" questions live.
4. **02** — don't memorize; learn its index structure so you can *find* any claim's code fast.
5. **04** — know the honest test story: what passed, what failed, and why counts differ.
6. Re-**05** — Q&A bank cold-drill.

## How to read the citations & markers

- **`S#`** = deck slide; **`§x.y`** = thesis section; **file paths** are repo-relative unless
  absolute; **artifact paths** point into `docs/09-Technical-Evaluation/`.
- **`UNVERIFIED:`** = claim attempted but not confirmable — the attempted check is named.
- **`*(inferred)*`** = rationale not recorded in code/docs/git — professional judgment, flagged.
- **`[USER INPUT NEEDED]`** = image-only slide content we refused to invent — fill from the deck.
- Historical numbers are always labeled ("reported"/"artifact") vs **executed in this session**
  — treat only the latter as current truth.
