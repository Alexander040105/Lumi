# LUMI Function & File Reference

This folder contains a complete, CHANGELOG-style inventory of the LUMI backend and frontend code, plus supporting files and geospatial reference data.

## Files

- [BACKEND.md](BACKEND.md) — every named function in the FastAPI backend.
- [FRONTEND.md](FRONTEND.md) — every function and component in the React frontend.
- [MISC.md](MISC.md) — supporting scripts, ETL, deployment, and configuration files.
- [GEOLOCATION.md](GEOLOCATION.md) — files and scripts used for province, municipality, and coordinate lookups.
- [UPDATE_PROMPT.md](UPDATE_PROMPT.md) — copy-paste prompt for future updates.

## How to use

Each entry shows the full function body, file path, line numbers, a one-line purpose, and an explanation. The `FRONTEND.md` is generated from the React source; the others are generated from Python, SQL, and configuration files.
