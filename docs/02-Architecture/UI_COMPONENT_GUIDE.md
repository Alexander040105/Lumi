# UI Component Guide

## Button
- Use for primary and secondary actions
- Variants: default, secondary, outline, ghost, link

## Card
- Use for grouping related content
- Compose CardHeader, CardContent, CardFooter

## Input
- Use for forms and data entry

## Dialog
- Use for modal flows

## Sheet
- Use for side panels and filters

## Dropdown Menu
- Use for quick action menus

## Toast (Sonner)
- Use for non-blocking notifications
- Example: toast.success("Saved")

## Form
- Use with react-hook-form and zod
- Use FormField and Input for validation

## Table
- Use for tabular data

## Skeleton
- Use to show loading states

## Badge
- Use for status or category labels

## Composition Tips
- Keep components small and reusable
- Prefer prop-driven variants over custom CSS
